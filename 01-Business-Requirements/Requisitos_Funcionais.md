# Requisitos Funcionais

## RF-001 - Autenticação

O sistema deve permitir que usuários realizem login utilizando e-mail e senha válidos.

## RF-002 - Recuperação de Senha

O sistema deve permitir recuperação de senha através do e-mail cadastrado.

## RF-003 - Cadastro de Usuários

O administrador deve poder cadastrar usuários.

## RF-004 - Edição de Usuários

O administrador deve poder editar usuários cadastrados.

## RF-005 - Exclusão de Usuários

O administrador deve poder excluir usuários cadastrados.

## RF-006 - Cadastro de Cursos

O instrutor deve poder cadastrar cursos.

## RF-007 - Edição de Cursos

O instrutor deve poder editar cursos existentes.

## RF-008 - Matrícula em Cursos

O colaborador deve poder se matricular em cursos disponíveis.

## RF-009 - Acompanhamento de Progresso

O colaborador deve visualizar o progresso dos cursos em andamento.

## RF-010 - Emissão de Certificados

O sistema deve emitir certificados automaticamente após a conclusão do curso.

## RF-011 - Relatórios Gerenciais

O administrador deve visualizar relatórios de treinamentos realizados.

## RF-012 - Controle de Perfis

O sistema deve restringir funcionalidades conforme o perfil do usuário.
