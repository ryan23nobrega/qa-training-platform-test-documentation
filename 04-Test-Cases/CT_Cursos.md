# Casos de Teste - Cursos

## CT-001 - Cadastro de curso válido

**Passos:**

1. Acessar módulo de cursos
2. Informar nome do curso
3. Informar descrição
4. Definir carga horária
5. Salvar

**Resultado esperado:**
Curso criado com sucesso

## CT-002 - Carga horária inválida

**Passos:**

1. Informar carga horária negativa ou zero

**Resultado esperado:**
Sistema deve bloquear e exibir erro
