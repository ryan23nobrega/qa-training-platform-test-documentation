# Requisitos Não Funcionais

## RNF-001 - Performance

O sistema deve responder às requisições em até 3 segundos para 95% das operações.

## RNF-002 - Disponibilidade

O sistema deve possuir disponibilidade mínima de 99%.

## RNF-003 - Segurança

As senhas devem ser armazenadas de forma criptografada.

## RNF-004 - Compatibilidade

O sistema deve funcionar nos navegadores Chrome, Firefox e Edge.

## RNF-005 - Usabilidade

As funcionalidades principais devem estar acessíveis em até 3 cliques.

## RNF-006 - Auditoria

O sistema deve registrar logs das ações críticas realizadas pelos usuários.

## RNF-007 - Escalabilidade

O sistema deve suportar até 5.000 usuários simultâneos.

## RNF-008 - Backup

Os dados devem possuir backup diário automático.
