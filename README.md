# QA Training Platform - Test Documentation Project

## 📌 Visão Geral

Este projeto simula a documentação completa de um processo de QA para uma plataforma de treinamentos corporativos, seguindo boas práticas de engenharia de testes e conceitos de maturidade baseados no TMMi.

---

## 🎯 Objetivo

Demonstrar habilidades em:

* Análise de requisitos
* Estratégia de testes
* Planejamento de testes
* Casos de teste
* Gestão de defeitos
* Rastreabilidade
* Métricas de qualidade
* Gestão de riscos
* Melhoria contínua

---

## 🧠 Abordagem

O projeto segue uma abordagem inspirada em:

* TMMi (Test Maturity Model Integration)
* Risk-Based Testing
* Boas práticas de QA corporativo

---

## 📂 Estrutura do Projeto

* 01-Business-Requirements → Requisitos de negócio e sistema
* 02-Test-Strategy → Estratégia de testes
* 03-Test-Plan → Planejamento de testes
* 04-Test-Cases → Casos de teste organizados por módulo
* 05-Traceability → Matriz de rastreabilidade
* 06-Defect-Management → Gestão de defeitos
* 07-Test-Execution → Relatório de execução
* 08-Metrics → Indicadores de qualidade
* 09-Risk-Management → Análise de riscos
* 10-Lessons-Learned → Lições aprendidas
* templates → Modelos reutilizáveis
